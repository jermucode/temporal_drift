These are cleaned up copies of my local working files for Temporal Drift, a 2d RPG I'm building with Raylib.

Maps are generated by reading text files, maps.c contains the custom parser that generates maps from these files.

Collisions handle adding items into inventory, removing items persistently from the game world, hitting walls and dialogue interaction.

Dialogue is also read from files.

The project started as checking to see if I can make a game with just prompting AI. I quickly realized I had no idea what's going on under the hood. From that, I kept only the player animation loop. The map parser, dialogue, collisions, inventory are all written by me.
